# АвтоДай.рф

P2P-аренда автомобилей напрямую между частными лицами — без прокатных
компаний и посредников. Telegram Mini App, MAX Mini App, адаптивный веб и
мобильная веб-версия (PWA) на одной кодовой базе.

Сервис «АвтоДай.рф» — информационный агрегатор/посредник (ст. 1253.1 ГК РФ):
не является стороной сделок аренды, не владеет автопарком и не несёт
ответственности за исполнение договоров между пользователями. Подробности —
в `public/legal/oferta.html` и `docs/legal/user-agreement.md`.

Архитектура построена на основе rideshare-бота **poehali74** — см.
`docs/AUDIT_REPORT.md` для полного отчёта об аудите исходного кода и списка
изменений при переносе на домен аренды авто.

## Стек

Node.js + TypeScript + Express, better-sqlite3, Telegraf (Telegram),
`@maxhub/max-bot-api` (MAX), sharp (обработка фото), ванильный JS на
фронтенде (без сборщика).

## Быстрый старт

```bash
cp .env.example .env   # заполните BOT_TOKEN как минимум
npm install
npm run dev             # ts-node-dev, hot reload
```

Продакшен-сборка:

```bash
npm run build
npm start
```

## Переменные окружения

См. `.env.example`. Обязательна только `BOT_TOKEN`. `WEBAPP_URL` и
`PUBLIC_ORIGIN` можно задать позже, когда появится публичный домен —
приложение и бот работают без них (просто без кнопки Mini App и без
дополнительной CSRF-проверки Origin соответственно).

## Структура

```
src/
  config.ts            конфигурация из ENV
  db/                  схема SQLite + каталог городов РФ
  services/            бизнес-логика (объявления, брони, рейтинги, договор...)
  server/              Express: middleware, роуты /api/*
  bot/                 Telegram- и MAX-боты, уведомления
  legal/               тексты Пользовательского соглашения
  jobs/                периодические задачи (напоминания, sweep броней)
public/
  index.html/app.js/styles.css   SPA (Telegram / MAX / веб-адаптер)
  legal/               статические страницы оферты и обработки ПДн
  promo/               HTML-баннеры, афиша, промпты для генерации графики
max-proxy/             опциональный RU-регион прокси для MAX (см. его README)
docs/                  отчёт аудита, юридические тексты в исходном виде
```

## Деплой на bothost

1. Задеплойте корень репозитория как основной бот-проект (главный файл —
   `dist/index.js` после `npm run build`, либо команда `npm start`).
2. Если MAX Mini App плохо открывается без VPN у части пользователей —
   разверните `max-proxy/` вторым бот-проектом в РФ-регионе (см. его README).
3. Пропишите `PUBLIC_ORIGIN` и `WEBAPP_URL` как только появится домен
   (кириллический `автодай.рф` или его punycode-эквивалент).
