# Прокси для MAX (РФ-регион)

Лёгкий обратный прокси без БД и бизнес-логики. Не хранит и не обрабатывает
никаких данных — просто форвардит каждый входящий запрос (любой метод, путь,
заголовки, тело — включая multipart-загрузку фото) на основной сервер
АвтоДай.рф и пересылает ответ обратно as-is.

## Зачем

MAX Mini App у части пользователей не открывается без VPN, если сервер стоит
за границей (мобильные операторы в РФ замедляют/обрывают связь с зарубежными
адресами). Этот прокси разворачивается отдельным ботом/проектом на
**РФ-регионе bothost** — у него российский IP, и запросы от MAX-клиентов до
него доходят напрямую, без VPN. Сам прокси только пересылает трафик дальше
на основной сервер — там всё как было: одна БД, один Express, один
Telegram-бот на long polling.

Telegram-трафик через прокси не идёт (Telegram работает и напрямую) — только
`WEBAPP_URL` в конфиге MAX (business.max.ru) указывает на домен этого прокси.

## Деплой на bothost

`dist/index.js` этой папки не требует npm-зависимостей вообще (только
встроенные модули Node) — это специально, чтобы не зависеть от того, ставит
ли bothost пакеты из `package.json` подпапки монорепозитория или только из
корневого. Как и в основном проекте, если меняете `src/index.ts`, обязательно
`npm run build` перед пушем.

Создайте **второй, отдельный бот-проект** на bothost из того же самого
репозитория и той же ветки — не нужно ни отдельного репозитория, ни выбора
подпапки как корня:

1. Git URL репозитория — тот же, что и у основного бота.
2. **Главный файл (точка входа)** — укажите `max-proxy/dist/index.js`
   (это поле в форме создания бота специально для таких случаев).
3. Регион — **РФ**.
4. Включите "Использовать домен" (порт 3000).
5. Переменные окружения:
   - `UPSTREAM_URL` — публичный адрес основного сервера
     (например, `https://bot1234.bothost.tech`), **обязательно с `https://`**.
6. Запустите — прокси должен подняться. Проверьте `https://<домен-прокси>/_proxy/health`
   в браузере: должен ответить `{"ok":true,"upstream":"..."}` — это подтверждает,
   что жив сам прокси, независимо от того, отвечает ли основной сервер.
7. Пропишите домен прокси в `WEBAPP_URL` конфига MAX Mini App (business.max.ru).
   `WEBAPP_URL` основного сервера (для Telegram) не трогайте — он остаётся как есть.

## Локальный запуск

```bash
cp .env.example .env   # заполните UPSTREAM_URL
npm install
npm run dev
```
